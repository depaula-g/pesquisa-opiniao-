# ⭐ Pesquisa de Opinião - TudoWeb

## 📋 Descrição

Este projeto foi desenvolvido em **Python** para realizar uma pesquisa de opinião com clientes da empresa fictícia **TudoWeb**, com o objetivo de identificar o grau de satisfação com o atendimento prestado.

## 🎯 Objetivo

O programa realiza uma pesquisa com **50 entrevistados**, coletando:

* 👤 Nome
* 🎂 Idade
* ⭐ Opinião sobre o atendimento

As opções são:

* `1` - EXCELENTE
* `2` - BOM
* `3` - RUIM

## 💻 Tecnologias utilizadas

## 🐍 Python
## 💻 Visual Studio Code

## 🔄 Funcionamento

O programa utiliza uma **estrutura de repetição** para realizar a pesquisa com 50 entrevistados.

Também utiliza **estruturas de decisão (`if` e `elif`)** para verificar a opinião informada e contabilizar as respostas **EXCELENTE** e **RUIM**.

Ao final, são exibidas as quantidades de respostas dessas duas categorias.

## 🧪 Teste

Foi realizado um teste com **10 entrevistados** para verificar o funcionamento do programa.
